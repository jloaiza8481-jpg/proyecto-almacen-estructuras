# Sistema de Logística de Almacén (Cola y Pila)
Proyecto grupal de Estructura de Datos - UNIMAR (Prof. Gabriel Villegas).

## Descripción del Proyecto
Aplicación desarrollada en Java por consola para la gestión de logística de un almacén, implementando estructuras de datos dinámicas basadas en nodos (Cola para la gestión de camiones en el muelle y Pila para los contenedores en los estantes), cumpliendo estrictamente con la restricción de no utilizar la librería java.util.

## Arquitectura y Módulos
- *Estructuras base:* Nodo, Cola, Pila
- *Lógica principal:* SistemaLogistica, Main
- *Control de calidad y seguridad:* Validador, EstructuraVaciaException, VisualizadorAlmacen
- *Trazabilidad:* bitacora.txt
